# Introduction

<aside>
    <strong>Base URL</strong>: <code>http://localhost/api</code>
</aside>

Welcome to the **MathGenius API** documentation.

This API powers the MathGenius educational platform — an AI-driven mathematics learning application that provides courses organized by filiere and classe, lessons, exercises, quizzes with AI-generated feedback, and performance analytics.

<aside>
    All authenticated endpoints require a <strong>Bearer token</strong> obtained via the <code>/api/login</code> endpoint.
</aside>
